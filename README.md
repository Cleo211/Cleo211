🧠 How I Learn

I have a slightly weird learning philosophy.

I don't consider something truly learned just because I can memorize the answer.

Usually my process looks like this:

        🤔
    "Why does this work?"
          ↓
      Understand
          ↓
      Explain it
          ↓
      Build it
          ↓
      Break it 💥
          ↓
      Fix it
          ↓
     Actually learn

Sometimes this makes learning slower.

But it also makes the things I understand stick much longer.
